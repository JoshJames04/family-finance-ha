# ADR-0000: ADR Template

Status: Accepted
Date: 2026-11-06

## Context

A long-lived financial application needs a durable record of why it is built
the way it is.

## Decision

Use lightweight ADRs (this format). Copy this file per decision; number
sequentially; never renumber.

## Consequences

Decisions are reviewable and revisitable; `main` carries the history.
